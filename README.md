# Projet de Dataviz : Le Hameçonnage en Chiffres

> **Réalisé par :** Charles Pons & Ahmed Moumni
> **Cadre :** Évaluation de fin de module (Option D3.js)

---

###  À propos de cette visualisation
L'objectif de cette interface est de mettre en évidence les principales portes d'entrée utilisées lors des cyberattaques par hameçonnage (phishing). Au lieu de nous concentrer sur les fuites de données globales, nous ciblons ici spécifiquement les méthodes d'approche des pirates informatiques pour l'année 2025-2026.

###  Source et nature des données
Le document `dataset.csv` joint au dépôt alimente le graphique. Il répertorie 6 catégories distinctes (Email, SMS, Réseaux Sociaux, Appels, Sites Web, Applications) accompagnées de leurs volumes d'incidents respectifs.

###  Spécifications techniques
Ce rendu respecte la consigne d'exclusivité à la bibliothèque **D3.js (v7)**. 

* **Structure :** Arborescence HTML5 et CSS3.
* **Rendu graphique :** SVG manipulé dynamiquement via JavaScript.
* **Interactions :** Événements de survol générant un affichage de données en temps réel via une infobulle personnalisée.
* **Hébergement :** Déploiement assuré par GitHub Pages.
